# Code of Conduct

This project is for everyone. Contributors and maintainers agree to:

- Be respectful. Disagree about the work, not about people.
- No harassment, insults, or personal attacks, including about anyone's legal situation.
- Never post anyone's private information: names of parties in private matters, addresses, phone numbers, case details.
- Keep discussion on the project: getting the law right and making it accessible.

Maintainers may edit or remove content and block participants who break these rules.
Report problems privately via the link in `SECURITY.md`.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
