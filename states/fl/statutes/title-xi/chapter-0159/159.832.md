# § 159.832 Purpose.

The purpose of this part is to allocate the state volume limitation imposed by s. 142(k)(5)(A) of the code on private activity bonds to finance qualified public educational facilities. No private activity bond subject to the limitation in s. 142(k)(5)(A) of the code shall be issued in this state unless a written confirmation therefor is issued pursuant to this part.

History: s. 49, ch. 2003-391.
