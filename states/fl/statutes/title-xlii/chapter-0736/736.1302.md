# § 736.1302 Severability clause.

If any provision of this code or its application to any person or circumstances is held invalid, the invalidity does not affect other provisions or applications of this code that can be given effect without the invalid provision or application, and to this end the provisions of this code are severable.

History: s. 13, ch. 2006-217.
